---
name: Capture quality gating
description: Safety rule for when PepScan may issue a visual screening outcome.
---

Required vial captures must be treated as a gate for the visual screen. When a required image is missing, unreadable, severely blurred, critically exposed, glare-obscured, or not framed against a distinguishable background, the outcome is unavailable and the user must retake the affected capture. This is not a review finding and is never a negative/clear screen.

**Why:** A low-quality photograph can hide the very visible issue the product is intended to surface. Presenting a standard visual verdict would imply assessment where none was possible.

**How to apply:** Preserve inspection context while sending the user back to the earliest affected capture. Do not send blocked images to optional AI analysis, merge them with AI verdicts, or use saved unavailable assessments as comparison baselines. Persist and display the retake limitation distinctly in reports and history.
